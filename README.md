# Night City 2045 — Атлас Мастера

Модуль для **Foundry VTT v12** и **Cyberpunk RED**. Он открывает интерактивную карту Найт-Сити с поиском и полными описаниями из [вики Мастера](https://defaulter444.github.io/cyberpunk-wiki/).

**Версия 0.2.1:** все 156 существующих мест сверены с книгой **Night City 2045 (2026)**. У 154 меток положение взято с районных карт книги; Night City University и Woodland Park обозначают территории, для которых сохранены общие ориентиры Атласа 2025. Карточки раздельно показывают старый код, номер в книге и фактические страницы. Фон без встроенных старых номеров не мешает исправленным меткам.

## Установка

В Foundry откройте **Setup → Add-on Modules → Install Module**, вставьте адрес в **Manifest URL** и нажмите **Install**:

```text
https://raw.githubusercontent.com/Defaulter444/CPR-Interface/main/module.json
```

В мире включите **Night City 2045 — Атлас Мастера** через **Manage Modules**, затем перезагрузите мир. Откройте **Game Settings → Configure Settings → Module Settings → Атлас Найт-Сити 2045 → Открыть карту**. У Мастера также появится кнопка карты в инструментах заметок сцены.

## Что доступно

- Карта с перемещением мышью, масштабированием колёсиком и кнопкой «Показать весь город».
- Поиск по названию, алиасу, коду карты и подтверждённому номеру первой карты; фильтр района, мест на карте и избранного.
- 549 карточек: 546 разделов вики, две именованные площадки внутри Woodland Park и статья о Плейлэнде у моря.
- 154 проверенные точки и 2 общих ориентира территорий; полное описание выбранного места, номер и страницы книги, ссылка на вики.
- Избранное и ручная привязка существующего места, у которого нет официальной точки. Такие метки можно удалить; официальные точки остаются справочными.

По умолчанию интерфейс открывается Мастеру. Настройка **«Открыть атлас игрокам»** разрешает участникам читать город, составлять свой маршрут и менять свою метку. Shift+M открывает карту. Избранное и прежние ручные метки сохраняются в клиентских настройках; общие правки кампании хранятся отдельно в мире. Исходный справочник не перезаписывается.

### Город и маршруты в 0.2.0

Нажмите **«Город»** в шапке атласа. Панель сворачивается и освобождает карту. Во вкладке **«Маршрут»** добавьте места или точки мышью, выберите транспорт. Расстояния учитывают пропорции изображения; ширина карты и скорости настраиваются Мастером. Это оценка, без пробок, дорожных правил и препятствий, пока вы не нарисовали сеть дорог.

Во вкладке Мастера можно нарисовать дороги и прямоугольные зоны угрозы. Дороги соединяются концами; визуальное пересечение двух отрезков само по себе перекрёсток не создаёт. При отсутствии связного пути движение по дорогам недоступно. Начало/конец могут соединяться с ближайшим узлом прямым отрезком с предупреждением. Готовая дорожная сеть другой карты не импортируется.

**«Переместить группу и время…»** требует подтверждения. Продвигается ровно один источник времени: активный Simple Calendar либо время мира Foundry. После успешного изменения часов перемещается общая метка. Личная метка записывается в флаг текущего пользователя. Общий маршрут публикует только Мастер. Сцены и токены не переносятся.

### Места, задания и торговля

Мастер создаёт свои места, редактирует карточки справочника через отдельные правки кампании, назначает изображение и торговую точку. **«Торговля»** открывает существующий магазин, закусочную или автомат; покупки, проверки доступа и предметы обслуживает модуль «Торговля Найт-Сити». **«Создать заказ»** открывает черновик в «Агенте» 0.17.3. Сохранение происходит в его обычном редакторе; связанные задания показываются с учётом видимости текущего пользователя.

Скрытие места исключает его из каталога. **Это не средство защиты секретов:** все данные города, включая скрытые правки, дороги, встречи и связи с магазинами, доступны участникам мира. Секреты храните в журналах с правами или в защищённом хранилище «Агента». Защита места запрещает удаление и замену импортом; снять её можно в редакторе.

Авторские встречи фильтруются по угрозе и времени суток. Результат — предпросмотр текста; актёры и бой автоматически не создаются. Кнопка показа карточки отправляет её описание в общий игровой чат.

### Перенос и сохранность

Экспорт содержит только общие данные города. Импорт принимает наш формат версии1, до2МБ, проверяет поля, ссылки, координаты и размеры коллекций. Перед заменой предлагается подтверждение и сохраняется резервная копия в клиентской настройке и JSON-файле. Исходные549 записей не меняются. Правки выполняет активный Мастер через последовательную очередь; устаревшее подтверждение импорта отклоняется.

Начните обновление в отдельном тестовом мире. Выключение модуля скрывает интерфейс, сохраняя данные кампании в настройках мира. Никаких миграций исходных актёров, торговых баз и сцен при запуске нет.

## Проверка после установки

1. Найдите **Посмертие**: карточка должна показывать точку **B1**, ссылку на вики и номер **75** первой карты.
2. Найдите **F4**: это **Night City University**; в книге №11, карта с.105, описание с.108. Это общий ориентир территории, а не вход в корпус. Старые коды и номера книги различаются.
3. Перетащите карту и измените масштаб. Выберите точку мышью и сравните карточку со списком.
4. Добавьте место в избранное, закройте и снова откройте атлас.
5. Выберите место без координат, нажмите «Поставить метку» и щёлкните по карте. Повторно откройте атлас, проверьте сохранение и удалите пользовательскую метку.
6. Зайдите игроком: по умолчанию карта недоступна. Включите доступ настройкой Мастера, проверьте личную метку и отсутствие инструментов Мастера.
7. Создайте два места и маршрут, проверьте публикацию, отмену путешествия и сохранение после перезагрузки. При отключённом доступе к карте игрок не должен открыть её через «Город».

Справочник включает 393 места без установленной точки. У них есть описание; координаты появляются только после вашей ручной привязки. Первая карта содержит авторские аннотации другой кампании: подтверждены 24 соответствия, остальные не используются для автоматического размещения.

## Разработка и проверка

Модуль работает без сборщика и сторонних зависимостей внутри Foundry. Для локальной проверки нужны Node.js 20+, Python 3, Playwright и Chromium. Сборка ZIP выполняется стандартной библиотекой Python.

```bash
npm ci
npm test
python3 scripts/test-browser.py
python3 scripts/build-release.py
python3 scripts/check-package.py
```

Готовые файлы выпуска появляются в `dist/`. Манифест загружается с GitHub Raw и содержит прямую ссылку на ZIP той же версии в GitHub Releases; вход в GitHub не нужен. Автоматические проверки используют модель API Foundry и чистые функции маршрутизации/хранилища; проверка в лицензированном Foundry выполняется по шагам выше. Совместимость заявлена для v12; v13 не проверялась.

При наличии сохранённых источников можно обновить данные командой `python3 scripts/build-locations.py --references /path/to/references`. Источники карты и текстов, их хеши и правила сопоставления описаны в [docs/data-sources.md](docs/data-sources.md). Основные сценарии и дальнейшие функции — в [docs/features.md](docs/features.md), концепты интерфейса — в [docs/design.md](docs/design.md).
