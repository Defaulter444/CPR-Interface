# Night City 2045: рабочий модуль для Мастера

Первый выпуск помогает Мастеру Cyberpunk RED найти место в Найт-Сити, увидеть его на карте и прочитать описание из авторской вики. Он предназначен для Foundry VTT v12 и открывается только пользователям с правами Мастера.

## Основной сценарий

1. Открыть карту Найт-Сити из интерфейса Foundry.
2. Найти место по названию, проверенному альтернативному названию или коду официальной карты; сузить список до района.
3. Выбрать запись в списке или метку на карте. Для места с известной меткой карта показывает её положение.
4. Прочитать полное описание и открыть первоисточник в вики. Добавить место в избранное, чтобы быстро вернуться к нему во время игры.
5. Добавить собственную метку кампании с названием и заметкой, указав её положение на карте.

Карта поддерживает масштабирование и перемещение. Каталог содержит 549 записей: 546 разделов указателя вики и три отдельные записи для отмеченных на карте мест, описанных внутри другого раздела или в отдельной статье. У 156 записей есть проверенная метка официальной карты; у остальных 393 координаты не назначены. Такие записи доступны в поиске и имеют описание, но не получают выдуманную точку на карте.

## Ключевые функции первого выпуска

| Функция | Польза во время игры |
| --- | --- |
| Карта, масштабирование и перемещение | Быстро перейти между районами и рассмотреть положение отмеченного места. |
| Поиск и фильтр района | Найти нужную локацию без просмотра сотен записей. |
| Список и интерактивные метки | Открывать одну карточку места из обоих способов навигации. |
| Полное описание и ссылка на вики | Читать справку прямо в Foundry и проверять контекст в источнике. |
| Избранное | Держать под рукой места текущей игровой сессии. |
| Собственные метки и заметки | Отмечать места кампании, отсутствующие в официальной карте. |
| Доступ для Мастера | Сохранять карту подготовки внутри интерфейса ведущего. |

Конкретное поведение сохранения избранного и пользовательских меток описано в инструкции к выпуску. Оригинальное описание вики и координаты официальной карты остаются справочными данными; метки кампании хранятся отдельно.

## Направления следующих выпусков

Общие заметки нескольких Мастеров, переключаемые слои фракций и опасности, маршруты, импорт и экспорт меток, а также дозированная выдача сведений игрокам требуют отдельного проектирования. Они не входят в заявленные возможности первого выпуска.

Дизайн строится вокруг карты в центре, краткого списка слева и карточки выбранного места справа. Поиск, район, избранное и собственные метки должны оставаться доступны без закрытия карты. Неоновые акценты подчёркивают выбранную точку и действия, а основной текст сохраняет спокойный фон и читаемый контраст.
